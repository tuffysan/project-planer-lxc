# Project Planer v15.2.2 — Complete Excel Template

## Ny komplett Excel-mall
Varje projekt kan nu ladda ner en enda omfattande Excel-arbetsbok med både importkompatibel Round-trip-data och övrigt projektinnehåll.

### Importkompatibelt
- Projektinformation
- Uppgifter/WBS
- Beroenden
- Risker/issues
- Ändringsärenden
- Resurser
- Kostnader
- Beslut
- Möten
- Åtgärder
- Nyttor

### Referensinnehåll i samma fil
- Projektmedlemmar
- Statusrapporter
- RAID
- Godkännanden
- Tidrapportering
- Dokument och bilagemetadata
- Kommentarer
- Baselines
- Anpassade fält
- Miljöer
- Leverabler
- Interfaces
- Testcykler
- Requirements traceability
- Cutover
- Historisk projekthälsa
- Cross-project dependencies
- Azure DevOps Work Item-länkar
- Omplaneringshistorik och detaljer
- Finanssammanfattning

Arbetsboken innehåller dessutom `LÄS MIG`, `Datamodell`, dashboard och dold metadata för säker round-trip.
