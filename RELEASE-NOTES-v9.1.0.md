# Project Planer v9.1.0 — Everyday UX + Excel & Reporting Pro

En gemensam vardagsyta för projektledaren: Mitt arbete, projektgenvägar, Excel Pro och rapporter samlat utan menyjakt.

Denna release är kumulativ och bygger vidare på föregående version. Fokus är sammanhållen UI/UX och att återanvända befintlig funktionalitet utan ny menysprawl.
