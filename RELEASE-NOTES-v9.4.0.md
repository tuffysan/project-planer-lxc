# Project Planer v9.4.0 — Resource & Capacity Planning

Resurscenter för kapacitet, överbeläggning, kompetenser och veckoplanering med direkt åtkomst till resursplaneringen.

Denna release är kumulativ och bygger vidare på föregående version. Fokus är sammanhållen UI/UX och att återanvända befintlig funktionalitet utan ny menysprawl.
