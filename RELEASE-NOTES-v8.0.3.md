# Project Planer v8.0.3 — Swedish UI Completion

This release completes the Swedish wording for the v8 experience and the v7.1–v8 feature surfaces that were still showing English labels while Swedish was selected.

Key areas updated:
- v8 overview
- Project Workspace
- Action Inbox
- Project Control
- Business cases / prioritization
- Scenario planning
- Resource directory
- Benefits realization
- Form builder
- Cross-project dependencies
- Managed templates
- Global navigation

Terminology is normalized around Swedish project-management language, e.g.:
- Inbox → Inkorg
- Workspace → Projektarbetsyta
- Business Case → Beslutsunderlag
- Benefits Realization → Nyttohemtagning
- Control Engine → Projektkontroll
- Resource Directory → Resursregister
- Change Request → Ändringsärende
- Health → Hälsopoäng / projektstatus
