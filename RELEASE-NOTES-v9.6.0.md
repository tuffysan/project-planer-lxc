# Project Planer v9.6.0 — Reporting Automation

Rapportcenter som binder ihop statusrapport, Report Studio, PDF/PPTX/Excel och exporthistorik till ett publiceringsflöde.

Denna release är kumulativ och bygger vidare på föregående version. Fokus är sammanhållen UI/UX och att återanvända befintlig funktionalitet utan ny menysprawl.
