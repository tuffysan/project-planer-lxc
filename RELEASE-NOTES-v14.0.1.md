# Project Planer v14.0.1 — Swedish UI & Translation Fix

Kumulativ release ovanpå v14.0.0 Ultimate Edition.

## Fokus
- Konsekvent svensk text i de användarnära vyerna.
- Svenska namn på centrala funktioner och arbetsflöden.
- Svenska visningsvärden för status, prioritet och resultat via ett centralt `sv`-filter.
- Interna databasvärden och routes lämnas oförändrade för bakåtkompatibilitet.
- Produkt- och tekniknamn som Azure DevOps, API, Excel, PDF och PowerPoint behålls.

Exempel:
- At risk → I riskzonen
- Not started → Ej påbörjad
- In progress → Pågår
- Done/Completed → Klar
- Blocked → Blockerad
- High/Low → Hög/Låg
- Action Inbox → Åtgärdsinkorg
- Report Studio → Rapportstudio
- Resource Planner → Resursplanering
