# Project Planer v5.0.3 – Visual UX Edition

Adds a visual project-management layer:
- Green / Orange / Red RAG project health
- deterministic 0–100 health score
- portfolio health dashboard
- visual project cockpit
- score rings, progress bars, status chips and attention indicators
- milestone visuals and activity timeline
- activity-status distribution
- responsive desktop/tablet/mobile layouts

RAG is derived from project data such as overdue tasks, blocked tasks, risk scores and pending changes.
