# Project Planer v8.0.4 — Visible App Version

UI/UX maintenance release.

- App version is now visible in the desktop header.
- App version is shown in the account menu.
- Footer explicitly shows `Appversion vX.Y.Z`.
- Admin Center contains a Systeminformation panel with the running application version.
- The displayed value comes from the application's `APP_VERSION`, so it reflects the deployed code rather than a hard-coded template label.
