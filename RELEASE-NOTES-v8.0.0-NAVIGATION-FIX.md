# Project Planer v8.0.0 — Navigation Fix

The v8.0.0 feature set is unchanged. The global navigation has been redesigned to prevent menu overload.

Main navigation:
- Overview
- My Work
- Projects
- Portfolio
- Resources & Finance
- Tools
- Admin (admins only)

Mobile/tablet:
- off-canvas hamburger navigation
- bottom bar: Home, Inbox, Work, Create, Menu

The obsolete v7 Home link and the long flat list of individual feature links have been removed from global navigation.
