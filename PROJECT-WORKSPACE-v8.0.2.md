# Project Planer v8.0.2 — Unified Project Workspace

The goal of this release is to make a project feel like one coherent work surface rather than a collection of independent features.

## Workspace structure

- Overview
- Plan
- Tasks
- Risk & change
- Resources
- Finance
- Documents
- Status report
- Meetings

## Overview

The overview combines:
- RAG and health score
- progress and end date
- unified attention queue
- milestones
- open / overdue / blocked task counts
- risk and change signals
- budget variance
- resource capacity
- incoming and outgoing cross-project dependencies
- recent audit activity
- PM Copilot entry point

## UX principles

- Context first: every tab remains inside the selected project.
- Attention before reporting: the first panel answers “what needs action?”
- Progressive disclosure: advanced tools remain reachable without crowding the main workspace.
- Action-oriented KPIs: cards link to the place where the PM can act.
- Responsive layouts for desktop, tablet and mobile.
- Status is communicated with text and structure, not color alone.
