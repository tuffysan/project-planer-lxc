# Project Planer v15.2.5 — Excel Start Center

## Excel utan projekt
- Ny permanent **Excel**-genväg i huvudnavigationen.
- Nytt **Excel Start Center** på `/excel`.
- **Skapa tom komplett Excel-mall** fungerar utan befintligt projekt.
- Mallen innehåller samma kompletta struktur som projektens Excel-export.
- Ny funktion **Importera Excel och skapa projekt**.
- Projektinformation läses från Excel och nytt projekt skapas automatiskt.
- Uppgifter, risker, changes, resurser, kostnader, beslut, möten, actions, nyttor och beroenden importeras vid projektskapandet.
- Användaren läggs automatiskt till som PM i det nya projektet.
- Efter import öppnas Project Cockpit direkt.
