# Project Planer v15.3.1 — Auto Project Codes

## Nytt i Multi-Project Excel
- Projektkod skapas automatiskt när ett projektnamn fylls i.
- Standardformat: `PRJ-001`, `PRJ-002`, `PRJ-003` ...
- Formeln ligger färdig på de första 100 projektraderna.
- Projektkoden kan skrivas över manuellt om företaget har en egen kodstandard.
- Importen förstår de auto-genererade koderna även om Excel inte har hunnit spara ett cached formula-resultat.
- Projektkod på Uppgifter, Risker, Resurser, Kostnader, Beslut, Möten, Åtgärder, Nyttor och Beroenden får rullista mot Projekt-bladet.
- Befintlig validering av unika projektkoder ligger kvar.

## Exempel
`Projekt A` på rad 2 → `PRJ-001`  
`Projekt B` på rad 3 → `PRJ-002`
