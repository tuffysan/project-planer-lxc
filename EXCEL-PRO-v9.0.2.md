# Excel Pro v9.0.2

Project Planer exposes three distinct Excel workflows:

1. **Project Workbook / Round-trip** — operational workbook intended for editing and re-import.
2. **Status Report Excel** — presentation-oriented report workbook with dashboard and read-only report tabs.
3. **Portfolio Excel** — multi-project management view with RAG, progress, forecast, schedule warnings and financials.

The round-trip workbook keeps technical IDs and hashes hidden, marks editable fields in green, formats date and money fields, applies filters, validations and conditional formatting, adds a visual overview, and configures print settings. Import remains preview-first with conflict detection, no deletion by omission and database backup before commit.
