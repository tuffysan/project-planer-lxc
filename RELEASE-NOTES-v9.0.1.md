# Project Planer v9.0.1 — Full Quality, UI/UX, Export & Reports

This release prioritizes user experience, reporting and export rather than adding another broad feature area.

## Reporting & export
- New project Report Studio.
- Executive PDF export.
- Steering-group PowerPoint export.
- Status-report Excel export.
- Complete ZIP report pack containing PDF, PowerPoint and Excel.
- Browser/print report preview.
- Export history per project with user, time, type, format and file name.
- Report exports use the same project status, forecast, milestones, risks, overdue work, changes and decisions.
- Excel Round-trip remains available as the operational/offline project workbook.

## UI/UX
- Report Studio integrated directly into Project Workspace and Next UX.
- Clear format cards based on intended use rather than technical file types alone.
- Responsive report cards, KPIs, preview and history.
- “Behöver uppmärksamhet” and management summary remain central to project reporting.

## Quality
- Version bumped to 9.0.1.
- New report export table created by startup schema migration.
- Report export activity is also written to audit history.
