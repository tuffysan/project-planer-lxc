# Project Planer v9.0.2 — Excel Pro Edition

v9.0.2 is fully focused on Excel quality, usability and export workflows.

## Excel Pro working workbook
- New visual Overview sheet with RAG, progress, attention signals, milestones and charts.
- Professional Excel tables with row striping and filters.
- Frozen headers, sensible column widths and wrapped text.
- Real Excel date formatting and numeric/currency formats.
- Conditional formatting for progress, blocked status and completed status.
- Editable fields are visually marked green.
- Read-only/reference views are visually separated.
- Technical `_ID` / `_Hash` columns remain hidden for safe round-trip.
- `_Metadata` remains very hidden.
- A4 print setup and fit-to-width configured.
- Workbook properties include project and application information.

## Three Excel workflows
1. Project workbook — edit and import back.
2. Status report Excel — presentation/reporting workbook with a dashboard.
3. Portfolio Excel — all accessible projects with RAG, forecast, progress, schedule warnings and financials.

## Portfolio Excel
- Portfolio dashboard.
- RAG distribution chart.
- Project table with progress bars and RAG conditional formatting.
- Planned vs forecast end dates.
- Overdue, blocked and high-risk counts.
- Planned cost and actual cost.

## Round-trip safety retained
- Stable IDs and snapshot hashes.
- Preview before import.
- Conflict detection.
- No deletion by omission.
- Automatic database backup before committed import.
